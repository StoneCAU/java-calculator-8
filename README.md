# 문자열 덧셈 계산기

## 프로젝트 개요
구분자로 분리된 양의 정수들의 합을 계산하는 콘솔 기반 계산기

### 주요 기능
- 기본 구분자(`,`, `:`) 지원
- 커스텀 구분자(`//구분자\n` 형식) 지원
- `BigInteger`를 사용한 큰 수 계산
- 잘못된 입력에 대한 예외 처리

### 실행 예시
```
입력: 1,2:3
출력: 결과 : 6

입력: //;\n1;2;3
출력: 결과 : 6
```

---

## 기능 요구 사항
- 쉼표(`,`) 또는 콜론(`:`)을 구분자로 숫자를 분리하여 합을 계산
- 커스텀 구분자 지원 (`//구분자\n` 형식)
- 잘못된 입력 시 `IllegalArgumentException` 발생

---

## 구현 기능 목록

### ✅ 입력
- [x] `Console.readLine()`을 사용하여 문자열 입력
- [x] 빈 문자열 입력 시 0 반환
- [x] 숫자 하나만 입력 시 해당 숫자 반환

### ✅ 구분자 처리
**기본 구분자**
- [x] 쉼표(`,`) 구분자 지원
- [x] 콜론(`:`) 구분자 지원

**커스텀 구분자**
- [x] 커스텀 구분자 형식(`//구분자\n`) 감지
- [x] `//`와 `\n` 사이에서 커스텀 구분자 추출
- [x] 커스텀 구분자 사용 시 기본 구분자 무시

### ✅ 계산
- [x] 분리된 문자열을 `BigInteger`로 변환
- [x] 모든 숫자의 합 계산
- [x] 결과를 `"결과 : {sum}"` 형식으로 출력

### ⚠️ 예외 처리
다음의 경우 `IllegalArgumentException` 발생

| 예외 상황 | 예시 |
|---------|------|
| 음수 또는 0 | `"1,-2,3"`, `"1,0,3"` |
| 숫자가 아닌 문자 | `"1,abc,3"`, `"1,2a,3"` |
| 0으로 시작하는 숫자 | `"01,002"` |
| 잘못된 시작 형식 | `",1,2"`, `"abc123"`, `"/1,2,3"` |
| 구분자 연속/시작/끝 | `"1,,2"`, `",1,2"`, `"1,2,"` |
| 설정되지 않은 구분자 | `"1.2.3"`, `"//;\n1.2.3"` |
| 두 글자 이상 커스텀 구분자 | `"//;;\n1;2"` |
| 숫자를 커스텀 구분자로 사용 | `"//1\n111"` |
| 불완전한 커스텀 구분자 형식 | `"//\n1,2"`, `"//;1;2;3"`, `"//;\n"` |

---

## 기타 고려 사항
- `Long` 범위 초과 가능성으로 `BigInteger` 사용
- 커스텀 구분자가 기본 구분자와 같아도 허용
  - 예: `"//,\n1,2,3"` → 유효
- 커스텀 구분자 지정 시 기본 구분자 무시
  - 예: `"//;\n1;2;3"` → 세미콜론만 구분자
  - 예: `"//;\n1;2,3"` → 쉼표는 일반 문자로 취급되어 예외 발생

## 🏗️ 아키텍처

### 클래스 다이어그램
```
┌─────────────┐
│ Application │ 진입점, 입출력 담당
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Calculator  │ 계산 로직 총괄
└──────┬──────┘
       │
       ▼
┌─────────────┐
│   Parser    │ 문자열 파싱 (구분자/숫자 분리)
└──────┬──────┘
       │
       ├─────────────┐
       ▼             ▼
┌─────────────┐ ┌─────────────┐
│  Delimiter  │ │   Numbers   │
└─────────────┘ └─────────────┘
구분자 정규식     숫자 검증/변환
     생성           (BigInteger)
```

### 📦 클래스별 책임

| 클래스 | 핵심 책임 | 주요 기능 |
|--------|----------|----------|
| **Application** | 프로그램 실행 | • 사용자 입출력<br>• Calculator 호출 |
| **Calculator** | 계산 수행 | • 빈 문자열 처리 (0 반환)<br>• Parser를 통한 파싱<br>• BigInteger 합계 계산 |
| **Parser** | 문자열 분석 | • 커스텀 구분자 감지 (`//구분자\n`)<br>• 구분자/숫자 부분 추출<br>• Delimiter, Numbers 객체 생성 |
| **Delimiter** | 구분자 관리 | • 기본 구분자: `,` `:` → 정규식 변환<br>• 커스텀 구분자: 유효성 검증 (1글자, 비숫자) |
| **Numbers** | 숫자 검증 | • 패턴 검증 (구분자 위치, 연속 방지)<br>• 토큰 검증 (숫자 형식, leading zero)<br>• BigInteger 리스트 변환 |

### 🔄 실행 흐름
```
1. Application: 문자열 입력 받기
              ↓
2. Calculator: 빈 문자열 체크 → Parser 호출
              ↓
3. Parser: "//;\n1;2;3" 분석
          ↓           ↓
   Delimiter(";")  Numbers("1;2;3")
          ↓           ↓
      정규식 생성    유효성 검증
              ↓
4. Numbers: [1, 2, 3] BigInteger 리스트 반환
              ↓
5. Calculator: sum() → 6
              ↓
6. Application: "결과 : 6" 출력
```
