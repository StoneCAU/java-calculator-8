# 문자열 덧셈 계산기

## 기능 요구 사항
- 쉼표(,) 또는 콜론(:)을 구분자로 숫자를 분리하여 합을 계산
- 커스텀 구분자 지원 (//구분자\n 형식)
- 잘못된 입력 시 IllegalArgumentException 발생

## 구현할 기능 목록

### 입력
- [x] Console.readLine()을 사용하여 문자열을 입력받는다
- [x] 빈 문자열 입력 시 0을 반환한다
- [x] 숫자 하나만 입력 시 해당 숫자를 반환한다

### 구분자 처리
- [x] 쉼표(,)를 구분자로 문자열을 분리한다
- [x] 콜론(:)을 구분자로 문자열을 분리한다
- [ ] 커스텀 구분자 형식(//구분자\n)을 감지한다
- [ ] //와 \n 사이에서 커스텀 구분자를 추출한다
- [ ] 커스텀 구분자가 있으면 커스텀 구분자만 사용하여 분리한다

### 계산
- [x] 분리된 문자열을 BigInteger로 변환한다
- [x] 모든 숫자의 합을 계산한다
- [x] 결과를 "결과 : {sum}" 형식으로 출력한다

### 예외 처리
다음의 경우 IllegalArgumentException 발생시키고 애플리케이션을 종료시킨다

- [ ] 분리된 숫자가 음수 또는 0인 경우
    - 예: "1,-2,3", "1,0,3"
- [ ] 분리된 문자열이 숫자가 아닌 경우
    - 예: "1,abc,3", "1,2a,3"
- [ ] 문자열이 숫자 또는 커스텀 구분자 형식으로 시작하지 않는 경우
    - 예: ",1,2", "abc123", "/1,2,3"
- [ ] 구분자가 연속으로 나오거나 문자열이 구분자로 시작/끝나는 경우
    - 예: "1,,2", ",1,2", "1,2,"
- [x] 커스텀 구분자가 두 글자 이상인 경우
    - 예: "//;;\n1;2"
- [x] 커스텀 구분자가 숫자인 경우
    - 예: "//1\n111"
- [x] 커스텀 구분자 형식이 불완전한 경우
    - 예: "//\n1,2" (구분자 없음), "//;1;2;3" (\n 없음), "//;\n" (숫자 없음)

### 기타 고려 사항
- Long 범위를 초과할 수 있으므로 BigInteger를 사용한다
- 커스텀 구분자가 기본 구분자(쉼표, 콜론)와 같아도 허용한다
    - 예: "//,\n1,2,3" -> 유효한 입력
- 커스텀 구분자 지정 시 해당 구분자만 사용하고 기본 구분자는 무시된다
    - 예: "//;\n1;2;3" -> 세미콜론만 구분자
    - 예: "//;\n1;2,3" -> 쉼표는 일반 문자로 취급되어 "2,3" 변환 실패로 예외 발생
